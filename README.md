
# FocusFlow – Student Task Manager

FocusFlow is a simple web-based task management application designed to help students organize their daily tasks and track their progress.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Track total, completed, and pending tasks
- Save tasks using Local Storage
- Dark mode for comfortable use
- Progress tracking

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project Structure

- `index.html` – Contains the structure of the application
- `style.css` – Contains the design and styling
- `app.js` – Handles task management, Local Storage, theme switching, and progress tracking

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Start adding and managing your tasks.

## Purpose

The purpose of FocusFlow is to provide students with a simple and user-friendly tool for managing their daily tasks and improving productivity.
